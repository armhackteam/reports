# Security & Coordinated Vulnerability Disclosure Policy

**Organization:** **ArmHack-Team** ([https://armhack.team](https://armhack.team)) — Armenian Cybersecurity, Ethical Hacking & Digital Defense Organization (Est. 2016, Yerevan, Armenia)  
**Research Division:** `ArmHack-Team (Cybersecurity Assessment & Defensive Engineering Unit)`  
**Publication Standard:** STIRS v2.0 (Standardized Technical Information & Risk Specification)

---

## 1. About ArmHack-Team & Scope of This Repository

**ArmHack-Team** provides comprehensive offensive and defensive cybersecurity services—including penetration testing, Red Teaming, AI-powered L7 WAF & Anti-DDoS protection (**L7 AI / ArmHack-CyberEngine**), digital forensics, and 24/7 incident response—alongside independent cryptographic and application security research.

This repository (`armhackteam/reports`) hosts public, sanitized security assessment reports, cryptographic evaluations, and architectural threat models. All published materials are governed by our [Legal & Ethical Research Disclaimer](./DISCLAIMER.md) ([Русская версия](./DISCLAIMER.ru.md)).

## 2. Reporting Inaccuracies, Vendor Updates, or Security Issues

If you are a vendor, protocol maintainer, or security researcher and wish to:
- Submit cryptographic proof of remediation or an updated version/hash where a documented architectural vector has been addressed;
- Request technical clarification regarding any published STIRS v2.0 advisory;
- Engage ArmHack-Team for penetration testing, infrastructure protection, or incident response, or report a security issue within ArmHack-Team's public assets;

Please open a structured GitHub Issue in this repository or contact us directly via our official platform at **[https://armhack.team](https://armhack.team)**.

## 3. Safe Harbor Assurance

**ArmHack-Team** supports independent, good-faith ethical hacking and defensive security research conducted in compliance with international standards (`ISO/IEC 29147`, `RFC 9116`).
