# Security & Coordinated Vulnerability Disclosure Policy

**Entity:** `ArmHack-Team (Cybersecurity Assessment & Defensive Engineering Unit)`  
**Standard:** STIRS v2.0 (Standardized Technical Information & Risk Specification)

---

## 1. Scope of This Repository

This repository (`armhackteam/reports`) hosts public, sanitized security assessment reports, cryptographic evaluations, and architectural threat models. All published materials are governed by our [Legal & Ethical Research Disclaimer](./DISCLAIMER.md) ([Русская версия](./DISCLAIMER.ru.md)).

## 2. Reporting Inaccuracies, Vendor Updates, or Remediation Evidence

If you are a vendor, protocol maintainer, or security engineer and wish to:
- Submit cryptographic proof of remediation or an updated version/hash where a documented architectural vector has been addressed;
- Request technical clarification regarding any published STIRS v2.0 advisory;
- Report an issue or vulnerability within ArmHack-Team's own public assets;

Please open a structured GitHub Issue in this repository or contact the team via our official portal at **[https://armhack.team](https://armhack.team)**.

## 3. Safe Harbor Assurance

`ArmHack-Team` supports independent, good-faith defensive security research conducted in compliance with international standards (ISO/IEC 29147, RFC 9116).
